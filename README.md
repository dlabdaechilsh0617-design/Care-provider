# 기계도움

사진 업로드 화면과 기계 정보 결과 영역을 제공하는 모바일 우선 웹사이트입니다. `index.html`을 브라우저에서 열어 화면을 볼 수 있습니다.

## 사진 판별 서버 연결

사진 보내기 버튼은 `POST /api/machines/identify`에 `multipart/form-data` 형식으로 `files` 항목들을 보냅니다. 현재 폴더에는 이 API 서버가 없으므로 사진 판별과 실제 전송은 동작하지 않습니다. API가 준비되지 않았을 때 화면은 이를 알리고, 임의의 기계 정보는 만들어 보여주지 않습니다.

성공 응답은 아래 JSON 구조를 사용합니다. 이름과 모델이 확인되고, 사용 순서를 뒷받침하는 출처가 하나 이상 있는 경우에만 `200` 응답을 보내야 합니다.

```json
{
  "machine_name": "제품 이름",
  "model": "모델명",
  "purpose": "제조사 설명서에 근거한 용도 설명",
  "steps": ["첫 번째 순서", "두 번째 순서"],
  "cautions": ["설명서에 적힌 주의 사항"],
  "sources": [
    {
      "title": "해당 모델의 공식 사용 설명서",
      "publisher": "제조사",
      "url": "https://manufacturer.example/manual"
    }
  ]
}
```

정확한 답을 보장할 수 없으면 성공한 것처럼 추정 결과를 보내지 말고, 사진을 더 요청하거나 모델 확인이 필요하다는 응답을 사용해야 합니다. 사용법과 안전 주의는 식별한 모델의 제조사 설명서 등 출처에서 확인하고, 출처 제목과 주소를 결과에 포함해 주세요.

## 실행

1. `.env`에 `AI_API_KEY`를 설정합니다. API 키는 브라우저 코드에 넣지 마세요.
2. 프로젝트 폴더의 Windows 명령 프롬프트에서 아래 명령을 실행합니다. PowerShell에서는 `npm.cmd run dev`를 사용하거나 `start-site.cmd`를 실행하세요.

```cmd
npm run dev
```

사이트 주소는 `http://localhost:3000`입니다. 서버 창을 닫으면 사이트 연결도 종료됩니다.

사진 분석은 OpenAI Responses API의 이미지 입력과 웹 검색을 사용합니다. 사진/PDF는 분석을 위해 OpenAI로 전송됩니다. 결과에는 웹 검색 응답에서 확인된 출처만 표시하며, 기계 모델이나 설명서 출처가 확인되지 않으면 사용법을 안내하지 않습니다.

홈 상단 챗봇은 `POST /api/chat`을 호출해 같은 `.env` 설정으로 AI 연결을 확인합니다. 대화 내용은 서버에 저장하지 않으며, 답변을 생성하기 위해 OpenAI로 전송됩니다.
